# CPU时钟源说明[](#cpu "永久链接至标题")

CPU有以下时钟源：


- 26M

- DCO

- 320M

- 480M

备注：
CPU主频最高可以达到320M，系统不支持运行到480M，可以通过分频使用240M。


## CPU主频切换说明[](#id1 "永久链接至标题")


- 可以根据业务需要动态的切频率来达到最优功耗,CPU主频切换相对来说比较复杂，SDK内部来实现。

- CPU主频最高可以达到320M
