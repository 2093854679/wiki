# 开发者社区[](#id1 "永久链接至标题")

[[English]](../../../en/v2.2.1/introduction/bk_community.html "../../../en/v2.2.1/introduction/bk_community.html")

Armino 社区由三部分组成:

> - Github 社区
> - 技术论坛
> - 尊贵客户支持


## Github 社区[](#github "永久链接至标题")

在 Armino Github Issue Forum: [https://github.com/bekencorp/armino](https://github.com/bekencorp/armino "https://github.com/bekencorp/armino") 上，您可以报告与特定 Armino 版本
相关的问题。


## 技术论坛[](#id2 "永久链接至标题")

博通集成技术论坛 [https://armino.bekencorp.com/](https://armino.bekencorp.com/ "https://armino.bekencorp.com/") 旨在提供一个开放式的技术交流平台，在这里您可以
发表与 Armino 技术相关的建议，观点，或者寻求技术支持。


## 尊贵客户支持[](#id3 "永久链接至标题")

如果您是博通集成的尊贵客户，您还可以通过尊贵客户通道寻求更快，更有效的支持:
[https://support.bekencorp.com/](https://support.bekencorp.com/ "https://support.bekencorp.com/")
