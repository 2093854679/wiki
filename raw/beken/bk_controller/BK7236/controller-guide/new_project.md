# 创建新工程

基于Controller SDK进行开发时，建议参考controller或者controller\_4wire创建新的工程，
比如在project目录创建xxx目录，对应的编译命令为make bk7236 RPOJECT\=xxx，新工程包含的必要文件也可以参考demo工程。

重要

在创建工程后，开发者需要参考 [demo工程介绍](demo_project.md) 中相关描述，根据实际情况正确配置I/O和config文件
