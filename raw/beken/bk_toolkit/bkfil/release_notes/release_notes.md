# release notes

<a id="v4-1-7"></a>

## v4.1.7

1. 新增 BL1DLV40 / BL1DLV41 格式固件的安全下载支持。
2. 拓展数据地址超出 flash 容量时，打印错误日志说明越界事实；该条数据不会被跳过，烧录流程与任务结果不受影响。
3. 修复模式切换时窗口状态与控件图标不同步的问题。
4. 优化烧录 safe json 时 type 为 ascii 的解密失败提示。
5. 修复烧录时百分比进度显示不完整的问题。

<a id="v4-1-6"></a>

## v4.1.6

1. 串口日志功能优化：改进日志实时显示，大幅降低看日志界面的 CPU 占用，并对界面进行美化。
2. 修复烧录外置 Flash 失败的问题。

<a id="v4-1-5"></a>

## v4.1.5

1. 研发模式新增「芯片选择」：可在 BK3515N 与 BK72xx 系列之间切换，选择自动记忆；选择 BK3515N 时按指定芯片执行下载 / 读取 / 擦除，选择 BK72xx 系列时由设备自动识别型号。
2. 新增 BK3515N 芯片支持。
3. 优化 BK7236N / BK7236Q 芯片的自动识别。
4. Windows / Linux：隐藏系统标题栏时，支持从窗口顶部边缘拖拽调整窗口大小。

<a id="v4-1-4"></a>

## v4.1.4

1. 完善 AI 能力接口服务：修复串口长期占用与失联问题；支持端口段自动发现；设置页可查看服务运行状态与实际监听端口；串口日志采集支持暂停 / 恢复；优化日志异步写入与轮转清理，降低刷屏。
2. 工厂模式：支持每个通道单独显示烧录进度，且显示列数可配置。
3. 修复 BK7236 / BK7258 通过 JSON 方式读取 eFuse 失败的问题。
4. 修复 BK7259 写 OTP 使能位设置及写权限失败的问题。

<a id="v4-1-3"></a>

## v4.1.3

1. 新增 TH25Q64UB Flash 支持。
2. BK7239N 芯片板级 CRC 校验失败时改为打印警告，不再直接抛出异常中断烧录。
3. 支持可配置 CRC 校验块大小（通过配置文件 `crc_verify_chunk_kb` 设置，默认 16K）。
4. 支持 BL1DLV30 格式固件烧录。
5. 研发模式串口配置弹窗支持持久化自定义波特率。
6. 文档优化：移除易误导的 MAC 地址固定地址示例，补充扩展数据配置免责说明。
7. 新增串口日志功能：支持多串口会话 Tab、快捷指令、HEX 收发、时间戳、显示格式切换、日志保存与全屏显示。
8. 新增 AI 能力接口服务：本机 HTTP 服务（默认端口 17631），提供原始命令（raw\_task）与串口日志能力，支持文件上传/下载，供外部工具/AI 调用。
9. 新增 WB25Q32JV Flash 支持。
10. 移除 SPID 校验拦截机制。
11. 通过 JSON 方式写入 OTP/eFuse 时，会将 permission 配置一并写入。

<a id="v4-1-2"></a>

## v4.1.2

1. 串口选择时默认波特率调整为 2000000。
2. 优化 Key 注入流程，修复注入流程中的异常问题。
3. 修复 BKFIL Windows 版被杀毒/安全软件误报的问题。
4. 修复选择 bin 时，因地址不可达导致界面长时间卡住的问题。
5. 新增 BK3653 芯片支持，修复读写efuse失败问题。
6. BK7259 下载与 eFuse/OTP 相关流程优化（含异常修复）。
7. 优化烧录顺序：先写入拓展数据（非 bin、非 OTP/eFuse），再烧录 bin。
8. 工厂模式交互优化：新增总烧录时长显示；支持部分烧录与全部烧录；Windows/Linux 配置文件迁移至 BKFIL 所在目录。
9. Mac 发布形态调整：GUI 提供单一 BKFIL 安装包；CLI 提供 x86\_64 / arm64 两个架构安装包（按机型选择）。
10. BIN 表编辑「起始地址 / 长度」改为弹窗确认并红色加粗高亮，且新增回退按钮一键恢复基准值；BIN 文件被外部重新生成且未手动编辑时，烧录前自动刷新基准长度。
11. 修复高波特率烧录失败时，错误提示中波特率显示与用户配置不一致（如配置 6 Mbps 但提示 3077000）的问题，现在统一显示用户配置的波特率。
