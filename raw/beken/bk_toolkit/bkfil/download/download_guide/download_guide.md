<a id="macos"></a>

# macos

说明：自 v4.1.2 起，Mac 下载产物调整为：GUI 提供一个 BKFIL 安装包；CLI 提供两个架构包（arm64 / x86\_64），需按机型选择。

<a id="id2"></a>

## GUI

1. 下载 .dmg 文件
2. 双击打开 .dmg 文件
3. 将 BKFIL.app 拖拽到 Applications 文件夹
4. 从 Applications 运行 BKFIL

<a id="id3"></a>

## CLI

1. 下载对应架构的 CLI 安装包（Apple Silicon 选 arm64，Intel 选 x86\_64）
2. 双击安装 .pkg
3. 在终端运行 bk\_loader
