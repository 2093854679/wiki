# Beken Flash Image Loader

---

Beken Flash Image Loader 简称 BKFIL，是博通集成芯片烧录固件的工具。

BKFIL 支持\*\*开发模式\*\*与\*\*工厂模式\*\*：开发模式适用于单设备研发与调试（参见快速开始、使用示例、功能介绍）；工厂模式适用于产线批量烧录（参见工厂模式章节）。

<a id="id1"></a>

## 主要功能

- 烧录固件
- 烧录OTP
- 烧录扩展数据
- 擦除flash
- 读取flash
- 读取efuse

<a id="id2"></a>

## 支持的平台

|  | windows(win7\+) | macos | linux |
| --- | --- | --- | --- |
| BKFIL(GUI) | yes | yes | yes |
| bk\_loader(CLI) | yes | yes | yes |

备注

Linux 版本仅支持 Ubuntu 22.04 及以上的发行版，更低版本（如 Ubuntu 20.04、18.04 等）暂不支持。
