# 4.3. 新建

进入新建群组页面后，App将自动开始新建流程，这时候设备 `层级指示灯` 开始闪烁，当某个节点完成配网后， `层级指示灯` 会显示对应层级的颜色。如下图。

<a id="id2"></a>
[![file_tree](../../../_assets/3cdf4110800208f839af-new_group_led.gif)](../../../_assets/3cdf4110800208f839af-new_group_led.gif)


设备组网中

App中会显示当前的流程状态，当所有设备都配网完成，App端提示: `群组创建成功` ，并返回到群组列表页面。如下图。

<a id="id3"></a>
