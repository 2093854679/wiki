# 5.2. 添加节点

在群组页面底部的操作视图中，点击 `添加节点` 按钮（如下图），App会跳转到空闲节点扫描页面。

<a id="id2"></a>
[![file_tree](../../../_assets/0bfc65e55575282bc1ac-group_action_add.jpg)](../../../_assets/0bfc65e55575282bc1ac-group_action_add.jpg)


添加节点

在扫描结果中，选择需要添加到群组中的节点，点击 `Add To Group` ，选择的节点 `层级指示灯` 将开始闪烁（组网状态）。当全部节点的 `层级指示灯` 停止闪烁并显示对应层级的颜色，表示添加完成。如下图。

<a id="id3"></a>
[![file_tree](../../../_assets/e376dbd796aa8a7966e1-add_scan.jpg)](../../../_assets/e376dbd796aa8a7966e1-add_scan.jpg)
