# 6.5. 节点删除

在拓扑结构中，点击想要删除的节点，在弹出的节点操作弹窗中，选择 `删除节点` ，会将该节点从群组中移除。
如果该节点下面有子节点，将进行网络重组，子节点将重新寻找新的父节点。
