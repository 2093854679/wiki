# 1\. 简介

Beken Wi-Fi Mesh App 是为 Beken 的 Wi-Fi Mesh 解决方案定制的移动端操作平台。
通过该App可以实现创建Mesh群组，查看群组网络拓扑、节点状态查看、OTA、增加、删除节点以及设备控制等一系列操作。

本示例将介绍Wi-Fi Mesh App结合LED灯的使用，包含扫描、配网、设备控制、OTA等功能。它将帮助您更好的了解Beken Wi-Fi Mesh的能力。
