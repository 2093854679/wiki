# 6\. 导出

参数调试完成后，点击工具栏中 Export -\> Export Code 菜单，即可将当前的参数导出为项目中可直接使用的代码文件，导出完成后文件目录会自动打开。

备注

- 导出前需先完成芯片选型（识别或手动选择），否则导出菜单不可用。工具会根据所选型号自动生成对应的算法头文件与使能宏，无需手动调整。
