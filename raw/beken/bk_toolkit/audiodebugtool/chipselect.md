# 4\. 芯片选型

本工具同时支持 **BK7258** 与 **BK7259**，两者的部分参数格式与下发协议不同。**在加载、下发或导出参数之前，必须先确定当前连接设备的芯片型号**，否则工具会拒绝相关操作，以避免按错误的协议读写设备。

界面顶部提供统一的“芯片选型栏”，包含：芯片型号下拉框、 **识别设备** 按钮、以及当前选型状态提示。

<a id="id2"></a>

## 4.1. 自动识别

连接并打开串口后，点击 **识别设备** 按钮，工具会向设备发送握手指令并读取芯片 ID 自动判定型号：

- 识别成功后，型号下拉框会自动切换为对应型号，状态显示 **已自动识别**。
- 识别成功后，工具会自动加载该设备当前的 EQ / 基础配置 / AEC 参数（见“选型后自动加载”）。

<a id="id3"></a>

## 4.2. 手动选择

若设备为旧固件、或识别无响应（超时），可直接从下拉框手动选择 **BK7258** 或 **BK7259**，状态显示 **手动选择**。手动选择同样会触发参数的自动加载。

备注

- 自动识别失败不代表设备异常，旧版本固件不支持握手识别，此时请手动选择型号即可正常使用。

<a id="id4"></a>

## 4.3. 选型后自动加载

无论自动识别还是手动选择，型号确定后工具都会按 EQ → 基础配置 → AEC 的顺序，自动读取设备当前参数并填充到各界面，无需再逐个界面手动点击“加载配置”。各界面的 **加载配置** 按钮依然保留，可随时手动重新读取。

若某一模块未在预期时间内返回，会给出提示，可在对应界面手动“加载配置”重试。

<a id="id5"></a>

## 4.4. 注意事项

备注

- **未完成选型前**，各界面的 **加载配置**、**在线调试** 以及菜单的 **导出代码** 均不可用（按钮置灰），需先完成识别或手动选型。
- **关闭串口（断开设备）后**，工具会复位芯片型号与已加载的参数。再次连接设备（尤其是更换为不同型号的设备，如 BK7258 与 BK7259 之间切换）时，需要重新识别或选择型号，避免沿用上一台设备的型号导致参数错配。
