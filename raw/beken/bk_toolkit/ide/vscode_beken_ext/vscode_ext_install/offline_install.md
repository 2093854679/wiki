# 离线安装

备注

注意:

离线情况（或内网环境）下，请确保依赖的插件（ms-vscode.cpptools，ms-vscode.vscode-serial-monitor）已经安装，否则Beken插件将无法激活。

ms-vscode.cpptools离线包下载地址: [https://marketplace.visualstudio.com/items?itemName\=ms-vscode.cpptools](https://marketplace.visualstudio.com/items)

ms-vscode.vscode-serial-monitor离线包下载地址: [https://marketplace.visualstudio.com/items?itemName\=ms-vscode.vscode-serial-monitor](https://marketplace.visualstudio.com/items)

Win7或VSCode低版本环境下如果无法安装最新版本的Serial Monitor，可以尝试下载下面的低版本Serial Monitor进行安装:

<https://marketplace.visualstudio.com/_apis/public/gallery/publishers/ms-vscode/vsextensions/vscode-serial-monitor/0.7.0/vspackage>

<a id="id2"></a>

## 1\. 获取离线安装文件

- 联系beken，获取.vsix安装包。
- 访问插件主页:`https://marketplace.visualstudio.com/items?itemName=beken-corp.vscode-beken-extension`
  ，点击右侧`Download Extension`下载.vsix安装包。

<a id="id3"></a>

## 2.安装扩展

- 打开 Visual Studio Code。
- 选择左侧的 “Extensions” 图标，或者按下 Ctrl\+Shift\+X 快捷键。
- 在右上角点击菜单按钮（三个点），选择 “Install from VSIX”。
- 导航到你保存了离线安装文件的位置，选择文件并点击 “Install”。
