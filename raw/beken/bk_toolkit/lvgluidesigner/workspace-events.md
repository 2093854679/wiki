# 🎯 事件系统

事件系统用于为组件添加交互功能，实现用户与界面的交互行为。

<a id="_2"></a>

## 📍 访问事件编辑器

事件编辑器位于**属性面板**的"事件"标签页中：

1. 选中要添加事件的组件
2. 在右侧属性面板中，点击 **"事件"** 标签页
3. 即可看到事件编辑器界面

<a id="_3"></a>

## 🎨 事件系统概述

事件系统允许您为组件配置交互行为，当用户与组件交互时（如点击、长按等），可以触发相应的动作（如页面跳转、修改属性等）。

<a id="_4"></a>

### 事件系统工作流程

```
用户交互 → 触发事件 → 执行动作 → 界面响应
```

例如：
\- 用户点击按钮 → 触发 `LV_EVENT_CLICKED` 事件 → 执行"页面跳转"动作 → 跳转到目标页面

<a id="_5"></a>

## ➕ 添加事件

<a id="1"></a>

### 步骤 1：打开事件编辑器

1. 选中要添加事件的组件
2. 在属性面板中找到 **"事件"** 标签页
3. 点击 **"添加事件"** 按钮

<a id="2"></a>

### 步骤 2：选择事件类型

选择触发事件的条件，常用事件类型包括：

**输入交互事件**
\- **LV\_EVENT\_CLICKED**：组件被点击时触发（最常用）
\- **LV\_EVENT\_DOUBLE\_CLICKED**：组件被双击时触发
\- **LV\_EVENT\_LONG\_PRESSED**：组件被长按时触发
\- **LV\_EVENT\_PRESSED**：组件被按下时触发
\- **LV\_EVENT\_RELEASED**：组件被释放时触发

**焦点事件**
\- **LV\_EVENT\_FOCUSED**：组件获得焦点时触发
\- **LV\_EVENT\_DEFOCUSED**：组件失去焦点时触发

**值变化事件**
\- **LV\_EVENT\_VALUE\_CHANGED**：组件值改变时触发（如滑块移动、输入框输入）

**滚动事件**
\- **LV\_EVENT\_SCROLL**：组件滚动时触发

**绘制事件（刷新时触发，不是点击）**
\- **LV\_EVENT\_DRAW\_MAIN**：绘制控件主体时触发
\- **LV\_EVENT\_DRAW\_POST**：子控件绘制完成后触发，适合叠加层
\- **LV\_EVENT\_DRAW\_TASK\_ADDED**：创建 draw task 时触发（自动开启 `SEND_DRAW_TASK_EVENTS`）

绘制事件的动作只能选 **自定义代码** 或 **调用函数**。回调运行在渲染期间，禁止修改控件属性/样式，也禁止创建或删除控件。设计器画布不会模拟这些事件，请通过编译/模拟器验证。

<a id="3"></a>

### 步骤 3：选择动作类型

选择事件触发后要执行的动作：

- **页面跳转**：跳转到指定页面
- **修改属性**：修改组件的一个或多个属性值
- **修改样式**：修改组件的一个或多个样式属性
- **调用函数**：调用自定义函数
- **自定义代码**：在事件回调中内联执行自定义代码

<a id="4"></a>

### 步骤 4：配置动作参数

根据选择的动作类型，配置相应的参数：

<a id="_6"></a>

#### 页面跳转参数

**目标页面**
\- 从下拉列表中选择要跳转到的页面

**动画类型**
\- **none**：无动画
\- **fade\_in / fade\_out**：淡入淡出
\- **move\_left / move\_right / move\_top / move\_bottom**：滑动效果
\- **over\_left / over\_right / over\_top / over\_bottom**：覆盖效果
\- **out\_left / out\_right / out\_top / out\_bottom**：移出效果

**动画时长**
\- 设置动画持续时间（毫秒），默认 300ms

**动画延迟**
\- 设置动画延迟时间（毫秒），默认 0ms

<a id="_7"></a>

#### 修改属性参数

**目标组件**
\- 选择要修改的组件（默认为当前组件）
\- 可以从下拉列表中选择页面中的其他组件

**属性列表**
\- 点击 **"添加属性"** 按钮
\- 选择要修改的属性（如 Text、Width、Height 等）
\- 输入新的属性值
\- 可以添加多个属性修改项

<a id="_8"></a>

#### 修改样式参数

**目标组件**
\- 选择要修改的组件（默认为当前组件）

**样式部分**
\- 选择要修改的样式部分（如 Main、Indicator、Scrollbar 等）

**样式状态**
\- 选择要修改的样式状态（如 Default、Pressed、Focused 等）

**样式属性列表**
\- 点击 **"添加样式属性"** 按钮
\- 选择要修改的样式属性（如背景颜色、字体大小、边框宽度等）
\- 输入新的样式属性值
\- 可以添加多个样式属性修改项

<a id="_9"></a>

#### 调用函数参数

**函数名**
\- 输入要调用的函数名称（如 `handleButtonClick`）
\- 在 `custom_func.c` 中实现该函数（详见 **[自定义代码](workspace-custom-code.md)**）

<a id="_10"></a>

#### 自定义代码参数

动作类型选择 **「自定义代码」** 时，可配置：

- **#include 和变量**：写入对应页面 `.c` 文件顶部
- **功能实现**：内联写入该事件的回调函数

详细说明请参阅 **[自定义代码](workspace-custom-code.md)**。

<a id="5"></a>

### 步骤 5：保存事件

1. **可选**：添加事件描述（用于说明事件用途，便于后续维护）
2. 点击 **确认** 按钮保存事件
3. 事件将出现在事件列表中

<a id="_11"></a>

## ✏️ 编辑事件

<a id="_12"></a>

### 编辑现有事件

1. 在事件列表中点击要编辑的事件
2. 修改事件类型、动作类型或参数
3. 点击 **确认** 按钮保存修改

<a id="_13"></a>

### 删除事件

有两种方式删除事件：

**方式 1：从事件列表删除**
\- 在事件列表中，点击事件右侧的 **删除** 按钮
\- 确认删除操作

**方式 2：从编辑模式删除**
\- 点击事件进入编辑模式
\- 点击编辑表单头部的 **删除** 按钮
\- 确认删除操作

<a id="_14"></a>

## 📋 事件列表

事件列表显示当前组件的所有事件，包括：

- **事件类型**：显示触发条件（如 CLICKED、LONG\_PRESSED）
- **动作类型**：显示执行的动作（如页面跳转、修改属性）
- **描述**：显示事件描述（如果有）
- **操作按钮**：编辑、删除

<a id="_15"></a>

## 🎯 事件连线可视化

在画布中，您可以查看事件与目标组件之间的连线关系：

1. 在画布工具栏的 **视图** 菜单中，选择 **显示事件连线**
2. 画布中将显示事件与目标组件之间的连线
3. 点击连线可以快速定位到对应的事件配置
