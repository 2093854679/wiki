# 唯一 ID (UID)

<a id="uid"></a>

## UID

BK7239 取 [PUF](bk_security_otp.md#security-otp) 中的 UID 前 128 Bits 作为系统唯一 ID，当 PUF 注册时，UID 即生成，每块设备唯一。
