# BekenIot 使用说明

下载 BekenIoT App：[BekenIoT App下载](../../../bk_toolkit/iotapp/app_download.md)

各工程的注册、登录与配网相同。配网之后的图传格式、分辨率、是否带屏以及低功耗/对讲见各参考工程文档。

1. 安装 App，注册并登录
2. 添加设备，选择 `可视门铃`
3. 选择非 5G Wi-Fi，通过 BLE 配网
4. 在扫描到的设备中点击 IP 匹配的项，完成配网
