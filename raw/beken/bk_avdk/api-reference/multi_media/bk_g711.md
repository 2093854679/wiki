# G711 APIs[](#g711-apis "永久链接至标题")


重要

The G711 API v1.0 is the lastest stable G711 APIs. All new applications should use G711 API v1.0.


## G711 API Categories[](#g711-api-categories "永久链接至标题")

G711 APIs:
:   - [`linear2alaw()`](#_CPPv411linear2alawi "linear2alaw") - G711A encodec pcm data to a-law data

    - [`alaw2linear()`](#_CPPv411alaw2linearh "alaw2linear") - G711A decodec a-law data to pcm data

    - [`linear2ulaw()`](#_CPPv411linear2ulawi "linear2ulaw") - G711U encodec pcm data to u-law data

    - [`ulaw2linear()`](#_CPPv411ulaw2linearh "ulaw2linear") - G711U decodec u-law data to pcm data
