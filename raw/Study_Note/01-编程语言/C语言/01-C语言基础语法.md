# C语言基础

## 一、数据类型

C是强类型语言，有`short`、`long`、`int`、`char`、`float`、`double`等内置数据类型，类型是贯穿C语言整个课程的核心概念。

`struct`、`union`、`enum`属于C的构造类型，用于自定义类型，扩充类型系统。

### 基本数据类型

| 类型 | 说明 | 字节数 |
|------|------|--------|
| `char` | 字符型 | 1 |
| `short` | 短整型 | 2 |
| `int` | 整型 | 4 |
| `long` | 长整型 | 4/8 |
| `float` | 单精度浮点 | 4 |
| `double` | 双精度浮点 | 8 |

## 二、变量

变量用来保存数据，数据是操作的对象，变量的"变"字意味着它可以在运行时被修改。

变量由**类型名+变量名**决定，定义变量需要为变量分配内存，可以在定义变量的同时做初始化。

```c
int i;                    // 声明变量
float f1 = 0.5, f2 = 0.8; // 声明并初始化
```

## 三、常量

```c
const int i = 100;        // 常量
const char* p = "hello world"; // 常量指针
```

运行中恒定、不可变，编译期便可确定。

## 四、数组

光有简单变量显然不够，我们需要数组，它模拟现实中相同类型的多个元素，这些对象是紧密相邻的，通过数组名+位置索引便能访问每个元素。

```c
int arr[10];              // 一维数组
int matrix[3][4];         // 二维数组
```

二维、三维、高维数组本质上还是线性的，二维数组通过模拟行列给人平面的感觉，实际存储上还是连续内存的方式。

数组是静态的，在定义的时候，数组的长度就已经确认，运行中无法伸缩，所以有时候我们不得不为应付扩充多分配一些空间。数组元素不管用多用少，它都在那里，有时候，我们会用一个`int n`去界定数组实际被使用的元素个数。

## 五、函数

函数封装行为，是模块化的最小单元，函数使得逻辑复用变得可能。

C语言是过程式的，现实世界都可以封装为一个个过程（函数），通过过程串联和编排模拟世界。

用C语言编程，行为和数据是分离的。调用函数的时候，调用者通过参数向函数传递信息，函数通过返回值向调用者反馈结果。

```c
int add(int a, int b) {
    return a + b;
}
```

函数最好是无副作用的，函数内应该尽量避免修改全局变量或者静态局部变量，更好的方式是通过参数传递进来，这样的函数只是逻辑的盒子，它满足线程安全的要求。

有了变量和函数，就可以编写简单的程序了。

## 七、结构体

内置数据类型不足以描绘现实世界，或者用内置类型描述不够直接，结构体用来模拟复合类型，它赋予了我们扩充类型系统的能力，我们把类型组合到一起构建更复杂的类型，而每个被组合的成分就叫成员变量。

```c
struct Student {
    int id;
    char name[20];
    float score;
};
```

结构体内的成分，对象通过点（`.`）运算符，指针通过箭头（`->`）访问成员。

```c
struct Student s;
s.id = 1;              // 点操作符

struct Student *p = &s;
p->id = 1;             // 箭头操作符
```

## 八、指针

C语言的灵魂是指针，指针带来弹性，指针的本质是地址。

需要区分指针和指针指向的对象，多个指针变量可指向同一个对象，一个指针不能同时指向多个对象。

指针相关的基本操作包括：赋值（修改指针指向），解引用（访问指针指向的对象），取地址（`&variable`），指针支持加减运算。

```c
int a = 10;
int *p = &a;           // 取地址
*p = 20;               // 解引用
```

因为指针变量要能覆盖整个内存空间，所以指针变量的长度等于字长，32位系统下32位4字节，64位系统下64位8字节。

### 指针类型

指针的含义远比上述丰富：

- **指针数组**：`int* p[n]`
- **数组指针**：`int (*p)[n]`
- **函数指针**：`ret_type (*pf)(param list)`
- **const指针**：`const char*`、`char* const`、`const char* const`
- **指向指针的指针**：`int **p`
- **void指针**：`void*`（通用指针，不能被解引用）

## 九、函数指针与回调

C源代码被编译链接后，函数被转换到可执行程序文件的text节，进程启动的时候，会把text节的内容装载到进程的代码段，代码段是C进程内存空间的一部分，所以任何C函数都会占一块内存空间，函数指针就是指向函数在代码段的第一行汇编指令，函数调用就会跳转到函数的第一个指令处执行。

```c
int (*func_ptr)(int, int) = add;  // 函数指针
int result = func_ptr(3, 4);      // 通过函数指针调用
```

函数指针经常被用来作为回调（callback），C语言也会用包含函数指针成员的结构体模拟OOP，本质上是把C++编译器做的事情，转给程序员来做。

## 十、字符串

`char*`是一类特殊的指针，它被称为C风格字符串，因为它总是以`'\0'`作为结尾的标识，所以要标识一个字符串，有一个`char`指针就够了，字符串的长度被0隐式指出。

```c
char str[] = "hello";
char *p = "world";
```

跟字符串相关的STD C API大多以`str`打头，比如`strlen`、`strcpy`、`strcat`、`strcmp`、`strtok`。

## 十一、内存和内存管理

指针提供了C语言直接操作底层内存的能力，C程序区分栈内存和堆内存：

- **栈内存**：函数内的局部变量，它随程序执行而动态伸缩，所以不要返回临时变量的指针，栈内存容量有限（8/16M），所以我们要避免在函数内创建过大的局部变量，要警惕递归爆栈。

- **堆内存**：也叫动态内存，它由一个叫动态内存配置器的标准库组件管理，`malloc`跟`free`必须配对，这是程序员的职责，动态分配的内存丢失引用就会导致内存泄漏，指向已释放的内存块俗称野（悬垂）指针。

```c
int *p = malloc(sizeof(int));  // 动态分配
*p = 10;
free(p);                       // 释放内存
```

## 十二、预处理

从C源文件到可执行程序需要经过预处理-编译-汇编-链接多个阶段，预处理阶段做替换、消除和扩充，预处理语句以`#`打头。

### 宏定义
```c
#define PI 3.14159
#define MAX(a, b) ((a) > (b) ? (a) : (b))
```

宏定义可以用`\`做行连接，`#`用来产生字符串，`##`用来拼接，宏定义的时候要注意加`()`避免操作符优先级干扰。

### 条件编译
```c
#ifdef DEBUG
    printf("Debug mode\n");
#endif
```

`#ifdef`、`#ifndef`、`#else`、`#elif`、`#endif`用来条件编译，为了避免头文件重复包含，经常用`#ifndef #define #endif`。

### 其他预处理指令
- `#include`：头文件包含
- `#pragma`：行为控制
- `#error`：编译时输出错误信息
- `#undef`：取消宏定义

### 预定义宏
`__FILE__`、`__LINE__`、`__DATE__`、`__TIME__`、`__STDC__`等标准预定义宏可以被用来做一些debug用途。

## 十三、typedef

`typedef`用来定义类型别名。比如`typedef int money_t;`，`money_t`比`int`更有含义。

```c
typedef int money_t;
money_t salary = 5000;
```

`typedef`也能用来为结构体取别名：

```c
typedef struct {
    int a;
    int b;
} xyz_t;
```

`typedef`也可以用来重定义函数指针类型：

```c
typedef void (*PF)(int a, int b);
PF func_ptr;  // PF是函数指针类型
```

## 十四、枚举

枚举能增加代码可读性和可维护性，枚举本质上是`int`，只是为了更有含义，将有限取值的几个`int`值放在一组。

```c
enum sex { 
    male = 1, 
    female 
};
```

可以在定义的时候赋值，比如`male=1`，后面的值依次递增1，如果不赋值则从0开始。

## 十五、联合体（union）

结构体和联合体（共用体）的区别在于：结构体的各个成员会占用不同的内存，互相之间没有影响；而共用体的所有成员占用同一段内存，修改一个成员会影响其余所有成员。

```c
union u_data {
    int n;
    char ch;
    double f;
};
```

其实本质上，联合体就是对一块内存的多种解释，大小按最大的来。

## 十六、位域（bitfield）

```c
struct SNField {
    unsigned char seq:7;        // frame sequence
    unsigned char startbit:1;   // indicate if it's starting frame 1 for yes
};
```

节省空间，在面向底层的编码，或者编写处理网络等程序时候用的比较多，注意这个语法特征是跟机器架构相关的。

## 十七、位操作

- **位与**：`&`
- **位或**：`|`
- **位取反**：`~`
- **位异或**：`^`
- **位移**：`<<` `>>`

```c
int a = 5;      // 0101
int b = 3;      // 0011
int c = a & b;  // 0001
```

## 十八、关键字

### static
- 修饰全局函数：表示模块内（编译单元）内可用
- 修饰局部变量：超越函数调用的生命周期，不存储在栈上，只会被初始化1次

### extern
声明外部变量。

### register
寄存器变量，建议编译器将变量放在寄存器里。

### volatile
告诉编译器不要做优化，每次从内存读取，不做寄存器优化。

### sizeof
求大小，可以作用于变量、类型、表达式。

```c
sizeof(int);        // 4
sizeof(arr);        // 数组大小
sizeof(struct Student); // 结构体大小
```

## 十九、可变参数

```c
void simple_printf(const char* fmt, ...) {
    va_list args;
    va_start(args, fmt);
    // 使用 va_arg(args, type) 获取参数
    va_end(args);
}
```

使用`va_list`、`va_start`、`va_arg`、`va_end`处理可变参数。

## 二十、C的高级感

### 泛型
Linux内核链表，通过offset和内嵌node，写出泛型链表。

### OOP
通过定义带函数指针成员变量的结构体，在运行中，为结构体对象设置上函数指针，模拟运行时绑定，实现类似OOP多态的感觉。

```c
typedef struct {
    void (*print)(void*);
    void (*destroy)(void*);
} Object;

Object obj;
obj.print = print_func;
obj.print(data);  // 多态调用
```

C语言虽然语法相对简单，但通过指针、函数指针、宏等机制，可以实现非常灵活和高效的编程模式。掌握这些基础概念是深入理解C语言的关键。
