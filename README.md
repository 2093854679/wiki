# Obsidian Vault

Core:
- `kb/`: compatibility entry point for `python -m kb`
- `raw/`: source documents
- `wiki/`: compiled notes
- `tools/kb/`: knowledge-base CLI implementation, templates, and static UI
- `tools/web2md/`: local web-to-Markdown crawler

Support:
- `archive/`: temporary or legacy files

Entry points:
- `AGENTS.md`
- `CLAUDE.md`
- `config.yaml`
