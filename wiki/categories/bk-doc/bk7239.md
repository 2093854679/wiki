## 与 BK7236 的关键差异

| | BK7236 | BK7239 |
|------|--------|--------|
| DVP Camera | 无 | **支持** |
| 多媒体 | 无 | DVP Camera + Video Transfer |
| 系统 API | os + event | os + event + **mem** (内存管理) |
| 外设 | 标准 | 无 Mailbox / Touch / QSPI / Flash (精简) |
| 蓝牙 | BLE + BT | 双模: dual_ble/dual_bt · 单模: single_ble |
