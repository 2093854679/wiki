## 与 BK7235 关键差异

| | BK7235 | BK7236 |
|------|--------|--------|
| CPU | ARM 单核 | ARM + RISC-V 双核 |
| WiFi API | v1.0 | **v2.0** (事件驱动) |
| OTA | 传统 Bootloader | **A/B 分区 + 安全 OTA** |
| 安全 | 基础 | **五层安全体系** |
| 多媒体 | DVP Camera + JPEG | 无 |
