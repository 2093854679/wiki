## 与 BK7236 的关键差异

| | BK7236 | BK7236N |
|------|--------|---------|
| USB | 不支持 | **支持** (bk_usb.md) |
| 低功耗 | 基础 | **新增**: Close Multimedia · CPU Vote Freq · Vote Boot CP1 · Lowpower Checklist |
| 构建 | build_config | build_config + **bk_build_faq.md** |
| 多媒体 | 无 | 无 |
