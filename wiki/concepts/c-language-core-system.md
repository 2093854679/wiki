# C语言核心知识体系

> **TLDR:** C语言的三大支柱——内存模型（栈/堆/全局区/代码段）、指针体系（多级指针/函数指针/数组指针）和编译链接（预处理→编译→汇编→链接）；掌握这三块即掌握C语言本质。

## 一、内存模型

C程序运行时内存分为四个区域：

```
高地址  ┌─────────────┐
        │   内核空间    │
        ├─────────────┤
        │    栈 (Stack) │ ← SP指针，向下增长，局部变量+返回地址
        │      ↓       │
        │      ↑       │
        │   堆 (Heap)   │ ← malloc/free管理，向上增长
        ├─────────────┤
        │  .bss (未初始化)│ ← 全局/静态变量，启动时清零
        │  .data (已初始化)│ ← 已初始化全局/静态变量
        ├─────────────┤
        │ .rodata (只读) │ ← 常量数据
        │  .text (代码)  │ ← 程序指令
低地址  └─────────────┘
```

- 栈自动管理但容量有限（8-16MB），不要返回局部变量地址，警惕递归爆栈
- 堆手动管理（malloc/free配对），内存泄漏和野指针是两大常见bug
- 全局区程序运行期间一直存在；.data占Flash，.bss不占Flash空间

## 二、指针体系

指针是C语言的灵魂，本质是内存地址。从简单到复杂：

| 指针类型 | 语法 | 用途 |
|---------|------|------|
| 基本指针 | `int *p` | 指向变量 |
| 数组指针 | `int (*p)[n]` | 指向数组（区别于指针数组`int *p[n]`） |
| 函数指针 | `int (*pf)(int,int)` | 指向函数，用于回调和多态 |
| void指针 | `void *p` | 通用指针，不能解引用 |
| const指针 | `const char *p` | 指向内容不可变 |
| 多级指针 | `int **p` | 指针的指针 |

核心规律：
- 指针变量大小=字长（32位系统4字节，64位系统8字节）
- 区分指针本身和指针指向的对象
- 函数名即函数地址，函数指针指向代码段第一条指令
- `typedef`可简化复杂指针类型声明

## 三、编译链接

源代码到可执行文件的全流程：

```
main.c ──[预处理]──> main.i ──[编译]──> main.s ──[汇编]──> main.o ─┐
lib.c  ──[预处理]──> lib.i  ──[编译]──> lib.s  ──[汇编]──> lib.o  ─┤
                                                         [链接]──> a.out / firmware.bin
lib.a (静态库) ────────────────────────────────────────────┘
```

- 预处理：宏展开、头文件展开、条件编译（`#define`/`#include`/`#ifdef`）
- 编译：C→汇编（语法检查、优化、生成符号）
- 汇编：汇编→机器码（.o目标文件，含符号表和重定位信息）
- 链接：合并所有.o和库→可执行文件；解决符号引用、分配地址

嵌入式特有概念：
- 分散加载：Flash中存储（加载域LR），运行时部分复制到RAM（执行域ER）
- XIP：代码直接在Flash中执行（节省RAM）
- .map文件：分析各段地址和大小，定位内存溢出

## 四、高级模式

- **OOP模拟**：带函数指针的结构体→运行时绑定→多态效果
- **泛型链表**：Linux内核通过`container_of`宏（offset计算）实现类型无关链表
- **回调机制**：函数指针作为参数传递→被调用者在适当时机回调→观察者模式基础
