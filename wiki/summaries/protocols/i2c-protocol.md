# I2C通信协议

> **Source:** [01-IIC.md](../../../raw/Study_Note/02-嵌入式开发/外设通信/01-IIC.md)
> **TLDR:** I2C是两线制（SCL+SDA）同步半双工串行总线，支持多主多从、100kHz-3.4MHz速率、7/10位地址、开漏+上拉的线与逻辑、硬件仲裁和时钟拉伸机制。

## Key Points

- **物理层**：SCL（时钟）+ SDA（数据），均需开漏输出+外部上拉电阻（典型4.7kΩ）；速率越高/电容越大→上拉电阻越小
- **时序基础**：起始条件（SCL高时SDA↓）、停止条件（SCL高时SDA↑）；SCL低时换数据，SCL高时采样；高位先发
- **应答机制**：每字节后跟1位ACK（0=应答）/NACK（1=非应答），由接收方驱动
- **读写格式**：7位地址+R/W位（0写1读）构成首字节；支持指定地址写/读和当前地址读
- **多主仲裁**：基于线与逻辑——多个主机同时发1时检测SDA是否被拉低；败方自动退出，不破坏总线
- **时钟拉伸**：从机拉低SCL延长高电平，通知主机等待；部分主机/外设对此支持有限
- **速度档位**：Standard(100kHz) / Fast(400kHz) / Fast-Plus(1MHz) / High-Speed(3.4MHz)
- **常见故障**：上拉电阻过大→上升沿慢→通信失败；地址冲突；时序不满足；设备未初始化；R/W位错误
