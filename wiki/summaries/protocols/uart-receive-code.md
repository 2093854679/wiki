# 串口接收代码实现

> **Source:** [07-串口接收代码.md](../../../raw/Study_Note/02-嵌入式开发/外设通信/07-串口接收代码.md)
> **TLDR:** STM32 UART接收的完整代码实现：HAL库中断接收、DMA+空闲中断不定长接收、环形缓冲区、超时判断、协议解析框架。

## Key Points

- **中断接收方案**：`HAL_UART_Receive_IT()`逐字节接收→RX回调中存入FIFO/环形缓冲区→主循环轮询解析
- **DMA+空闲中断（IDLE）**：配置DMA循环模式接收→IDLE中断触发表示一帧结束→`__HAL_DMA_GET_COUNTER()`获取接收长度→数据处理→重新使能
- **环形缓冲区**：头尾指针循环移动，无内存拷贝开销；需处理满/空判断
- **超时判断**：定时器定时检查接收缓冲区是否有新数据且多久未收到新数据→认为帧结束
- **协议解析**：帧头+长度+数据+校验+帧尾的通用帧结构；状态机解析避免阻塞
- **实际代码要点**：临界区保护（关中断）、缓冲区溢出检测、错误处理（ORE/NE/FE）
